Format JSON Généré

Le système génère maintenant un JSON avec la structure exacte demandée :

{
  "users": {
    "name": "Utilisateurs",
    "pages": {
      "index": { "name": "Index", "permissions": ["read"] },
      "roles": {
        "name": "Roles",
        "pages": {
          "manage": { "name": "Manage", "permissions": ["edit"] }
        }
      }
    }
  }
}

Cette structure permet une navigation hiérarchique et une meilleure organisation des permissions.
